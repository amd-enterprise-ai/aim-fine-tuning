# CLI reference

The [CLI concept page](../concepts/cli.md) explains the workflow and the
boundary between common CLI inputs and engine configuration.

For the complete command, options, and environment-variable reference, run:
```bash
aim_fine_tune --help
```
The current CLI supports `list-recipes`, and `train`.
