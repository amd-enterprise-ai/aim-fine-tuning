# Standard interfaces

Contracts shared by fine-tuning images and their surrounding execution
systems. These interfaces describe how a training image receives configuration,
data, and output paths.

- [Standardized SFT image interface](standard-sft-image-interface.md)

More training methods may be added in the future, each with its own interface specification.
